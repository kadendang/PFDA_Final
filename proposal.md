# Title
Invisighoul

## Repository
https://github.com/kadendang/PFDA_Final.git

## Description
An arcade game where the player collects as many items as possible while avoiding an invisible enemy using audio cues.
This program uses computer graphics and user input to create an active experience.

## Features
- Player character
	- The player moves their character up, down, left, or right with WASD. The player cannot move through the walls of the maze.
- Collectable items
	- Items randomly spawn. When the player touches an item, the item disappears, the score increases, and a new item spawns.
- Hostile enemy with dynamic audio
	- An invisible enemy moves around the map. The closer the enemy is to the player, the louder the music gets.
    The higher the score, the faster it moves.

## Challenges
- Impassable maze walls
- Enemy movement
- Change audio volume based on proximity

## Outcomes
Ideal Outcome:
- A game with a movable player character, an enemy that ends the game on contact, impassable maze walls,
  randomly spawning collectables, a visible score that updates when items are collected, and audio that changes
  based on the player and enemy positions.

Minimal Viable Outcome:
- A game with a movable player character and an enemy that ends the game on contact.
